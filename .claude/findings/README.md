# Findings

Working memory for the current stretch of work. Two files here are tracked by git: this README and `NOW.md` (where the work stands). Everything else in this folder is scratch: a lane's handoff, a wide map a next step reads, a draft. It is ignored by git and deleted when the work it served lands.

- Durable research moves to `docs/research/` (dated).
- A decision moves to `docs/decisions.md` the turn it is made.
- A changed fact moves to its owner doc (`docs/README.md` maps them).
